# Ideas
## architecture
The BfME2 extensive support should be a module of the application.
The support for Sacred2 would be another module.

## modules
The BfME2 extension features:
	- packing and unpacking .big files
	- parsing .ini files
	- user saved games and heroes attributed to a specific version of the mod

## requirements
When switching mods: create temporary directories instead of changing the current files one by one.
